Project overview

A production-ready hospital web presence

The site helps patients and attendants discover services, call emergency numbers quickly, review specialists, and submit appointment requests with clear accessibility and SEO foundations.

Purpose & goals

Improve trust, reduce emergency contact friction, digitize appointment inquiries, and communicate facilities in a mobile-first experience.

Target users

Emergency patients, families, OPD visitors, referring doctors, ambulance coordinators, and local residents around Purnea.

Core features

Responsive pages, service directory, doctor profiles, appointment form, API-ready lead capture, user guide, and deployment notes.

Facilities

Neuro, cardio, critical care, and diagnostics

Medical team

Specialists listed from hospital material

Appointment system

Request OPD or admission support

Submit a request and the hospital desk can follow up. The frontend validates required fields and sends JSON to the Spring Boot REST API.

System architecture

Static responsive frontend → REST API /api/appointments → Spring service validation → MySQL appointments table with indexed phone, status, and requested date columns.

Documentation

Implementation notes

UI/UX

Mobile-first cards, high-contrast emergency CTA, sticky navigation, WCAG-friendly labels, generous tap targets, Inter typography, teal/red healthcare palette.

Backend

Spring Boot REST architecture with DTO-style validation through entity constraints, centralized error handling, CORS configuration, and MySQL persistence.

Security

Server-side validation, least-privilege DB credentials through environment variables, no secrets in frontend code, and clear extension points for authentication.

AI roadmap

Optional future triage chatbot, appointment prioritization, multilingual FAQs, and automated call-center summaries with human review for safety.
